# تطبيق الجوال - بنك الدم (مستشفى ابن سينا - جنين)

مشروع Expo جاهز: كل المكتبات معرّفة بـ `package.json`، فما في داعي تثبتي شي لحالك.

## التشغيل (أمرين بس)
```bash
npm install
npx expo start
```
بعدها امسحي الـ QR بتطبيق **Expo Go** على تلفونك (لازم التلفون والكمبيوتر على نفس الواي فاي).

## تجربة سريعة (بيانات وهمية)
- رقم جوال: أي رقم 10 خانات يبدأ بـ 05، وكلمة مرور 6 أحرف أو أكثر.
- المستخدم الوهمي: ريم أحمد، فصيلة O+ (بتشوفي الطلبات المتوافقة معها بس).

## الشاشات (13)
| الجزء | الشاشات |
|---|---|
| الدخول | الافتتاح، الترحيب، تسجيل الدخول، إنشاء حساب (3 خطوات) |
| التبويبات الثلاثة | الرئيسية، الطلبات (نشطة / سابقة)، المزيد |
| تفاصيل | تفاصيل الطلب، شاشة النجاح |
| المزيد | معلوماتي الشخصية، سجل التبرعات، الإعدادات، الدعم والمساعدة |

## مبدأ المشروع: كل شي موجود لازم يشتغل فعلاً
- شلنا كل ما كان شكله بس: الخريطة المرسومة، المتبرعين، الإشعارات الداخلية، مخزون الدم، محادثة الدعم بردود جاهزة، "نسيت كلمة المرور"، ومفاتيح الإعدادات اللي ما بتأثر على شي.
- أي رقم بالتطبيق بيظهر بس إذا بياناته متوفرة فعلاً (مثلاً إحصائيات التبرعات وموعد التبرع القادم بتختفي إذا السيرفر ما بعتهم).
- لما `USE_MOCK = true` بيظهر شريط "وضع تجريبي" بالرئيسية، وبيختفي لحاله لما نربط الباك اند.

## شو بكل مجلد جوا `src/`
| المجلد | الشرح |
|---|---|
| `screens/` | الشاشات (كل شاشة بملف) |
| `components/` | أجزاء بنستخدمها بأكثر من شاشة (زر، حقل، كارد، قطرة الدم...) |
| `navigation/` | تنقل التطبيق بين الشاشات |
| `services/` | كل اتصال بالباك اند. هون بتتبدل البيانات الوهمية بالحقيقية |
| `context/` | بيانات المستخدم المسجّل (متاحة لكل الشاشات) |
| `i18n/` | الترجمة `ar.json` و`en.json` |
| `theme/` | الألوان والخطوط والظلال والمسافات |
| `data/` | البيانات الوهمية |
| `utils/` | دوال صغيرة مساعدة (تواريخ، تحقق، توافق الفصائل) |
| `config.js` | الإعدادات: رابط الباك اند، `USE_MOCK`، رقم المستشفى، أيام الراحة |

## الربط مع الباك اند (لما يجهز التوثيق)
1. غيّري `API_BASE_URL` و`USE_MOCK = false` بـ `src/config.js`.
2. طابقي مسارات وأسماء الحقول بملفات `src/services/` مع توثيق الـ API.
   المسارات الحالية (`/auth/login`، `/requests/compatible`، `/inventory`، `/donors/nearby`...) تخمين.
3. الباك اند لازم يؤكد هالـ endpoints: الرد على الطلب (في طريقي / اعتذار)، وسجل التبرعات. وحقل `lastDonationDate` بجواب تسجيل الدخول (لموعد التبرع القادم).

## قواعد الكود
- ما في نص مكتوب مباشرة بالكود: كله من `ar.json` و`en.json`.
- بنستخدم `flexDirection: 'row'` وبينقلب لحاله بالعربي. ما نستخدم `left` و`right` للمحتوى.
- كل شاشة: state فوق، دوال بالنص، شكل الشاشة (JSX) تحت، التنسيق آخر الملف.
- كل جزء بالكود إله تعليق بيشرح شو بيعمل.
- النصوص بتستخدم المكون `AppText` (الخط Cairo)، والألوان من `theme/index.js`.
